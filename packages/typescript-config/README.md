# 📦 @repo/typescript-config

Shared **TypeScript configurations** for React apps, Node.js tools, and Playwright E2E projects, ensuring consistent settings, strict type-safety, and easier maintenance across the monorepo.

## ✨ Introduction

Managing multiple apps and packages in a monorepo can lead to **duplicated** or **inconsistent** TypeScript configs. The `@repo/typescript-config` package solves this by providing a set of **base configs** you can extend for:  

- ⚛️ React / Vite applications  
- ⚙️ Node.js tooling (e.g. Vite configs, scripts)  
- 🎭 Playwright E2E tests  

This keeps TypeScript strictness consistent everywhere while still allowing flexibility at the app level.
